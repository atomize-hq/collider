- Storybook governance is consumer-owned:
  - `storybook/component-specs/*.json` declares each component's tier, required story kinds, source entrypoint, and Figma node reference.
  - `storybook/story-inventory.json` maps implemented Storybook IDs to governance kinds.
  - `artifacts/storybook/proof-coverage.json` is generated by `pnpm govern:storybook-proof`.
- Source code is the runtime authority, Storybook is the executable state/interaction proof surface, and Figma is the reusable design representation. Code migration alone does not imply Figma parity; each completed primitive was explicitly carried through all three surfaces.
- The canonical Figma taxonomy is:
  - **UI Primitives**: Collider-owned reusable UI controls, including the 23 migrated primitives.
  - **AI Elements Reference**: higher-level `src/components/ai-elements/*` examples retained primarily as source/reference material.
  - **Product Compositions**: create only when the first real composition is ready; do not add an empty placeholder page.
- Figma theme behavior comes from the canonical `Collider Tokens` variable collection. The UI Primitives page owns the explicit light/dark mode; the `UI Primitives / Theme Canvas` frame must have no explicit variable-mode override so it inherits the page mode.

### Key Patterns Discovered

- Interactive-tier components require at least `default`, `state-matrix`, `keyboard`, `focus`, and `docs`; this branch also includes `variant-matrix` and `actions` where appropriate.
- Use exact story IDs in both the component spec and inventory. For Batch 6 these are `primitives-scrollarea--*` and `primitives-carousel--*`.
- ScrollArea's Radix viewport must itself be keyboard focusable. The story browser's keyboard simulation does not perform native browser scrolling for PageDown, so the governance suite separately proves receipt of the keyboard event and proves scrolling through an explicit action.
- Figma components must bind color, typography, spacing, radius, stroke width, and applicable opacity to variables in the canonical `Collider Tokens` collection rather than merely assigning matching raw values.
- Keep component-set and variant `clipsContent` disabled when focus rings or controls extend beyond the visual control. Presentation frames must be sized/inset so buttons and borders do not overflow or get cut off.
- Use real vector icon nodes in Figma rather than text glyphs for controls.
- After light-mode validation, restore the UI Primitives page to canonical dark mode and verify that the Theme Canvas has an empty explicit-variable-mode map.
- Source changes that feed `ds-curated-collider-owned-primitives` require a fresh evidence/curation/review/install loop. Batch 6's ScrollArea source is not one of the current selected local-source files, and both curation checks passed unchanged.

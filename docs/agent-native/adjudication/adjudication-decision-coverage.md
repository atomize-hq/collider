## Recommended shortlist and genuine alternatives

1. **Preferred proof candidate:** public AgentKit controller/protocol plus suitable React regions, selective Toolkit, one owner-routed bridge, shared Collider-defined Workstream/Control Plane/Lane behavior.
2. **Headless-first variant:** retain AgentKit behavior but replace/combine presentation using public hooks and Toolkit/other UI. Select only if protocol/lifecycle mapping works but reference React composition does not.
3. **Presentation-first variant:** substantial Toolkit reuse with a different or purpose-built single controller. Fair fallback if AgentKit lifecycle/mapping cost exceeds its demonstrated behavioral value; not a mandate to preserve AI Elements.
4. **Bounded coherent frontend fork:** name the lifecycle/presentation mismatch, own one controller, record exact changed scope, test burden, upstream/security policy and exit route. May outrank a complicated adapter once measured.
5. **Broader owner-preserving framework/fork:** keep eligible if a retained product surface measurably justifies backend substitution and ongoing ownership costs. Not currently selected or demonstrated. Reject only the variant that duplicates or replaces existing semantic/execution authority without an explicit product decision.

Selective source ejection is an ownership/distribution axis available within several variants, not a separate mutually exclusive architecture. Likewise a sidecar is a deployment choice, not an execution-authority grant.

# Installed ds-skills

The skills in this directory are generated, receipt-checked outputs of the
release pinned in `ds-skills.release.json`, not Collider-authored instructions.
Run `just ds-skills-install` to install or explicitly upgrade them and
`just ds-skills-check` to verify them. Do not edit installed files.

Product authoring belongs to the ds-skills repository. Collider owns its project
configuration in `ds-skills.project.json`, application source and design data;
its Figma validation profile is `src/figma/validation-profile.json`.
